
## 1. Actors

يشير مصطلح **Actor** إلى أي جهة تتفاعل مباشرة مع النظام أو تطلب منه تنفيذ عملية أو تستقبل نتيجة منه.

| Actor | النوع | مستوى التفاعل | المسؤولية الأساسية |
| --- | --- | --- | --- |
| موظف المخزون | Primary Actor | مباشر | إدخال بيانات الرصيد الافتتاحي وإدارة تفاصيل الأصناف والمخازن. |
| مدير النظام | Primary / Administrative Actor | مباشر | مراجعة العمليات وإدارة صلاحيات الوصول عند تفعيل نظام الصلاحيات. |
| النظام | System Actor | داخلي | تنفيذ التحقق، إدارة البيانات، عرض الرسائل، وتطبيق Business Rules. |
| Mock Data Provider | Supporting Actor | غير مباشر | توفير بيانات الأصناف والمخازن في المرحلة الحالية. |
| Database أو API مستقبلي | Supporting Actor | غير مباشر | توفير التخزين الدائم أو مصادر البيانات عند الانتقال إلى مرحلة لاحقة. |

### 2.1 موظف المخزون — Inventory Clerk

يمثل موظف المخزون المستخدم الأساسي للنظام. يتعامل مع شاشة الأرصدة الافتتاحية لإدخال البيانات الفعلية الموجودة في المخازن عند بداية تشغيل النظام.

| الصلاحية أو العملية | الوصف |
| --- | --- |
| فتح الشاشة | الوصول إلى شاشة الأرصدة الافتتاحية. |
| إدخال Header | إدخال رقم الوثيقة والتاريخ والمستخدم والبيان. |
| إضافة Details | اختيار الصنف والمخزن وإدخال الكمية والسعر وتاريخ الصلاحية. |
| تعديل البيانات | تصحيح أو تحديث أي سجل تمت إضافته. |
| حذف البيانات | إزالة سجل بعد تأكيد العملية. |
| حفظ الوثيقة | طلب حفظ البيانات بعد استكمال شروط التحقق. |

### 2.2 مدير النظام — System Administrator

يمثل مدير النظام الجهة المسؤولة عن الإشراف على النظام والمستخدمين، وقد يمتلك صلاحيات أوسع من موظف المخزون. في النسخة الحالية لا يتم تنفيذ نظام Authorization كامل، لكن يتم تعريف هذا الدور ضمن التحليل ليكون أساسًا للتوسعة المستقبلية.

| المسؤولية | الوصف |
| --- | --- |
| إدارة الوصول | تحديد المستخدمين الذين يستطيعون فتح الشاشة. |
| مراجعة العمليات | متابعة عمليات الإدخال والتعديل والحذف والحفظ. |
| إدارة الإعدادات | ضبط الأصناف والمخازن والصلاحيات في الإصدارات المستقبلية. |
| مراجعة الأخطاء | متابعة الرسائل والأخطاء التشغيلية. |

### 2.3 النظام — System

النظام ليس مستخدمًا بشريًا، لكنه يمثل Actor داخليًا ينفذ العمليات الآلية المطلوبة.

| العملية الآلية | الوصف |
| --- | --- |
| تحميل الشاشة | تجهيز مكونات الشاشة والبيانات الأولية. |
| التحقق | التأكد من اختيار الصنف والمخزن وصحة الكمية. |
| إدارة المعرفات | حفظ `ItemId` و`WarehouseId` داخليًا. |
| عرض الأسماء | عرض `ItemName` و`WarehouseName` بدل المعرفات الداخلية. |
| إدارة النتائج | عرض رسائل النجاح أو الخطأ. |
| تحديث الجدول | إعادة عرض `Details` بعد الإضافة أو التعديل أو الحذف. |

## 2. Stakeholders

يشير مصطلح **Stakeholder** إلى كل جهة لها مصلحة في النظام أو تتأثر بنتائجه، حتى لو لم تتفاعل معه مباشرة.

| Stakeholder | المصلحة في النظام |
| --- | --- |
| إدارة المستودعات | الحصول على أرصدة افتتاحية دقيقة وقابلة للمراجعة. |
| الإدارة المالية | الاستفادة من بيانات الكميات والأسعار عند الحاجة إلى المطابقة المالية. |
| إدارة النظام وتقنية المعلومات | ضمان قابلية التشغيل والصيانة والتوسعة. |
| المستخدمون التشغيليون | تنفيذ الإدخال اليومي بطريقة سهلة وواضحة. |
| فريق التطوير | امتلاك بنية واضحة قابلة للاختبار والتعديل. |
| الإدارة العليا | الحصول على بيانات موثوقة عن الوضع الافتتاحي للمخزون. |
